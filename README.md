# 🎯 CODTECH Internship - Task 1

## 📝 Project Title:
**Interactive Quiz Application**

---

## 📌 Task Description:
As part of the **Frontend Web Development Internship** at **CODTECH IT SOLUTIONS PVT. LTD**, this task involved building a **dynamic quiz application** using JavaScript. The quiz allows users to answer multiple-choice questions, view instant feedback, and track their score.

---

## 🛠️ Technologies Used:
- HTML
- CSS (External Styling)
- JavaScript

---

## ✅ Features Implemented:
- ✅ Dynamic question loading
- ✅ Interactive user interface
- ✅ Real-time answer feedback (green/red highlight)
- ✅ Timer (15 seconds) for each question
- ✅ Score tracking and result display
- ✅ Responsive design
- ✅ Clean and modern color scheme

---

## 📁 Folder Structure:
```
interactive-quiz-app/
├── interactive quiz app.html        → Main HTML file with all logic
├── style.css         → External CSS for styling
├── README.md         → This file

```

---

## 🚀 How to Run the Project:
1. Download the project folder or clone the repository.
2. Open `interactive quiz app.html` in any modern web browser.
3. Answer the quiz questions and view your score at the end!
